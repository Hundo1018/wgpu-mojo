# Code of Conduct

## The short version

Be decent to people. Assume good faith. Keep technical criticism about the
work, never about the person doing it.

## Expected behaviour

- Be respectful of differing viewpoints, experience levels and native
  languages. This project is maintained by a non-native English speaker and
  welcomes contributors who are too — imperfect English is not a defect.
- Give and accept constructive feedback gracefully. "This struct layout is
  wrong, here is the header" is useful. "This is garbage" is not.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults, or personal attacks of any kind.
- Discriminatory language or imagery, and unwelcome attention of a sexual
  nature.
- Publishing others' private information without explicit permission.
- Sustained disruption of discussions, issues, or reviews.

## Scope

This applies in every project space — issues, pull requests, discussions,
commit messages and code review — and whenever someone is representing the
project in public.

## Enforcement

Report unacceptable behaviour to the maintainer at **f74169@gmail.com**.
Reports are handled confidentially, and you will get a response.

The maintainer may edit or remove contributions that violate this document,
and may temporarily or permanently block anyone whose behaviour is harmful or
repeated. Enforcement is proportionate: a first, good-faith misstep gets a
private word, not a ban.

If you disagree with an enforcement decision, say so by email and it will be
reconsidered once.
